# 费用组成

费用分三部分，不在仓库中保留未经当前核对的报价：

| 部分 | 如何产生 |
| --- | --- |
| 模型 API | 按所用模型和实际输入、输出量计费；读取长曲线或长聊天可能增加输入量 |
| 常驻计算 | 平台或服务器的 CPU、内存、运行时长 |
| 存储与流量 | 持久卷、日志和缓存保留量，以及平台的流量规则 |

本机运行不需要租云主机，但仍可能产生模型 API 费用。ChatGPT 订阅与本项目默认的 DeepSeek API 分开配置和计费。

默认按需查询、曲线抽样及缓存可以减少重复数据和模型输入，但不能据此承诺固定月费。部署前应以所选平台和模型供应商的当前官方计价为准；试用额度、免费方案、休眠规则和网络限制也需要当时核对。

此项目的源码打包脚本只生成本机目录，不会开通服务、购买套餐或启用计费资源。
