# 微信调整偏好

普通内容调整可以直接在微信里完成，无需再找 GPT 确认。它使用的是已有工具和字段，不会在聊天中修改项目代码。

## 长期要求与临时要求

长期要求：

> 以后每天的日报只讲睡眠、恢复和训练建议，控制在 300 字以内。先给结论，再给最多三项依据。请保存为长期偏好。

临时要求：

> 今天先只分析睡眠，详细一点，不修改我平时的日报设置。

bot 应在收到长期要求后更新私有工作区的 `PREFERENCES.md`，读回核对，再确认已保存。临时要求只影响当次回答。保存失败时应如实说明，不能仅凭口头回复声称设置已持久化。

可以继续说“把你保存的日报偏好列给我看”，核对文件中的内容。偏好依赖模型按规则使用文件工具，项目不会把一句自然语言直接变成未经核对的系统配置。

## 哪些能直接改

| 要求 | 处理方式 |
| --- | --- |
| 改主题、字数、语气、结构、展示重点 | 写入偏好，后续聊天和日报读取 |
| 少展示某些指标，优先分析其他指标 | 调整内容；不等于底层停止读取该字段 |
| 选择已有工具的分类、回看天数、曲线详细程度 | 在工具已有参数和上限内选择 |
| 增加一种尚未接入的数据、改计算或单位 | 修改并测试 MCP 代码 |
| 严格禁止某数据进入模型 | 修改数据过滤层，提示词或“不要展示”不足以保证 |
| 改推送时间、暂停推送、改收件人 | 修改并验证任务配置；当前 bot 不具备任务管理权限 |

如果请求涉及定时任务，bot 可以将意图记录为“待配置”，但不能声称任务已经改好。

## 偏好保存在哪里

默认本机路径为 `.private/coach-workspace/PREFERENCES.md`。云端则位于 `OPENCLAW_WORKSPACE_DIR` 指定的持久工作区。

- `coach/PREFERENCES.md` 是公开仓库的初始模板，不是个人设置。
- `SOUL.md`、`AGENTS.md` 是项目管理的规则，更新前会保存旧版备份。
- `PREFERENCES.md`、`USER.md`、`MEMORY.md` 已存在时，准备脚本不会覆盖。
- 每次聊天及日报都先读偏好，因此旧的日报任务说明也通过工作区规则应用最新设置。

更换电脑或迁移云端时，需要私下迁移运行工作区并保留持久存储；不要把个人文件复制回公开仓库。
